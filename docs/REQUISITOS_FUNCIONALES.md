## Errores HTTP comunes

`src/middlewares/errorHandler.js` convierte errores de aplicación en JSON `{ "error": "..." }`, devuelve 404 para rutas desconocidas, 400 para JSON mal formado y 500 para errores no clasificados (sin exponer el detalle interno en la respuesta).
